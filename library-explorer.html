Click Load FASTQ File(s) to open one or more Nanopore FASTQ files — or Load Example to explore a synthetic dataset.

Each file should be named so it contains its plate well (e.g. E12 or H6) — one file (or more) per well. Paste the construct's ORF above, set the AA min/max range to scan, then click Analyze.

For each position in range, Library Explorer searches every read (both strands) for the focal codon flanked by the conserved amino acids on either side — the same logic as grep -o 'FLANK_UP[ACGT]{3}FLANK_DOWN' — and tallies which 3 bases appear there.
